# UI and UX review 002: iTop Wrap wireframes (2026-11-10)

Scope: everything on the canvas after review 001. That includes the Dark mode page, the ticket description, the new "needs you" rule and escalated-first order, the four "When things go wrong" screens, and the shared dropdown.

Method: scripted scans of all 33 artboard files, plus the rendered click-throughs already recorded in review 001 (pass 2) and UX-FLOWS.md. Nothing new was clicked for this review; findings 1 to 3 come from reading code and are certain from it.

antislop mode: during. Direction: DESIGN.md, ENERGY 1 / RHYTHM 1 / MOTION 1.

## Findings

| # | Priority | Rule | Where | Finding |
|---|---|---|---|---|
| 1 | HIGH | R-26 | Search fields in Main, Menu bar, CMDB, Organizations, People | The search fields accept typing but filter nothing. Only the searchDemo tweak shows a result. They look interactive and do nothing, which R-26 doesn't allow. |
| 2 | HIGH | R-26 | Server URL (Sign in), "Time for this entry" (composer), "Time spent" (Resolve), CMDB search ("vpn") | These fields have a fixed value and no change handler, so you **can't type in them at all**: they're locked. Anyone trying to correct the time or the server URL is stuck. |
| 3 | MEDIUM | C-2 | Main, More menu → Copy ref | It closes the menu with no feedback. There's no "Copied R-000412" note, so you can't tell it worked. |
| 4 | MEDIUM | UX logic | "Needs you" rule | **Escalated TTO and mine can't happen.** In iTop, TTO ("time to own") escalates only while nobody owns the ticket, and it stops once someone is assigned. So under the current rule, teal and notifications only ever fire for **TTR**, and an unowned ticket breaching TTO in your team never gets your attention. |
| 5 | MEDIUM | UX (U1) | Menu bar | The org filter still hides the running timer's ticket. |
| 6 | MEDIUM | UX (U2) | Menu bar | Still no "Assign to me" on unassigned rows. The main window and Organizations have it. |
| 7 | MEDIUM | UX | Offline state | The "… will work again when you're back online" message appears in the top bar, far from the button you clicked. |
| 8 | MEDIUM | UX | Session expired | "Sign in again" accepts an empty password. |
| 9 | MEDIUM | UX | Ticket changed state | Pressing send while the banner is showing does nothing visible. |
| 10 | LOW | R-25 (latent) | Main, CMDB, Organizations, People | The base link colour is still the fixed dark teal `#0F6E56` (2.69:1 in dark). Every link checked has its own mode-aware colour, so nothing fails today, but any new link without one would. Make the fallback inherit the text colour instead. |

## What passes

- **R-02:** no em dashes in any of the 33 artboards.
- **R-24:** no `href="#"` placeholder links.
- **R-25:** all text pairings use the contrast-checked tokens, and the focus ring passes 3:1 in both modes.
- **R-27:** empty, loading, error, offline, expired and conflict states all exist.
- **R-34:** a dark copy of every screen exists, including the four states.
- **R-39:** the spinners stop under Reduce motion; headings run h1 then h2 with no skipped levels.
- **Liveliness:** the dials and the motif are held. The teal accent is now even rarer (one ticket in the sample), which keeps its meaning sharp.
